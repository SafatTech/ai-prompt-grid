# Gemini LinkedIn Profile Picture Prompts for CV & Office Photos

**Quick answer:** A LinkedIn profile picture prompt for Gemini starts with "edit this photo," then names the clothes, the backdrop, and the light, and tells the model to keep the face. The same wording works as a LinkedIn profile picture prompt for ChatGPT. Use a recent, front-facing photo in even light. These looks are for LinkedIn, a CV or resume, a company page, and email. A passport-size prompt is included below, with a note that it does not produce a compliant ID photo.

## Before you paste

- Face the camera. Daylight from a window is enough. Skip sunglasses and heavy shadows.
- Keep head and shoulders in frame, and crop other people out first.
- Change the setting, not the person. Ask for the same face, age, skin tone, beard, glasses, and head covering.

## If it does not look like you

Send this in the same chat. It keeps the new clothes, backdrop and light, and only asks for the face back.

```
Keep the clothes, background and lighting exactly as they are. Only fix the face so it matches the original photo: same eyes, nose, lips, jawline, age and natural skin tone. Remove any skin smoothing or lightening.
```

A few things that usually cause the drift:

1. Plastic skin. Ask for natural skin texture.
2. A lighter skin tone than the photo. Say "keep the skin tone exactly the same."
3. A younger face. Say the age stays.
4. A busy backdrop. Soft and plain reads more clearly on a small profile circle.
5. A missing hijab, glasses or beard. If they wear them day to day, say so.

Gemini's image model is sometimes called Nano Banana. The same LinkedIn profile picture prompt works there: attach the photo, paste the prompt, and fix the face in that chat if it drifts. In ChatGPT you can comment on one spot, such as "straighten the collar," instead of rewriting the whole prompt.

## FAQ

### What is a good LinkedIn profile picture prompt for Gemini?

Start with the navy blazer prompt. It changes the outfit and the backdrop and keeps the face. Women can use the black blazer, hijab, dupatta or saree prompts. Men who want a suit can use the charcoal suit prompt.

### Can I use the same prompt in ChatGPT?

Yes. Paste it with the photo attached. The charcoal suit prompt is written as a longer list, which ChatGPT follows closely.

### Is this a Gemini AI resume photo prompt?

The plain-background CV prompt is the one to use for a resume or job portal. It keeps their own clothes, including glasses if they wear them. It is still not an official ID photo.

### Can I make a passport-size photo with Gemini?

Official passport, visa and ID photos have strict rules, and many authorities reject AI-edited or digitally altered photos. Check your issuing authority's requirements; this prompt does not produce a compliant ID photo.

### What if the office photo changes my shirt?

The modern office, outdoor and home office prompts are written to keep the clothes. If the shirt still changes, send a follow-up that says "keep the original clothing exactly."

### What size should a LinkedIn photo be?

Square crops work well for the profile circle. LinkedIn accepts a large PNG or JPG. A 1:1 result is the simplest starting point.
